## Usage

> run

``` sh
bash <(curl -L https://raw.githubusercontent.com/samwhelp/note-about-ubuntu-mate/refs/heads/gh-pages/_demo/scripts/mate-keybind/mate-keybind.sh)
```


> or run

``` sh
bash <(wget -q https://raw.githubusercontent.com/samwhelp/note-about-ubuntu-mate/refs/heads/gh-pages/_demo/scripts/mate-keybind/mate-keybind.sh -O - )
```


> or run

``` sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/samwhelp/note-about-ubuntu-mate/refs/heads/gh-pages/_demo/scripts/mate-keybind/mate-keybind.sh || wget -q https://raw.githubusercontent.com/samwhelp/note-about-ubuntu-mate/refs/heads/gh-pages/_demo/scripts/mate-keybind/mate-keybind.sh -O - )"
```
